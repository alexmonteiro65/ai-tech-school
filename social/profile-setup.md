# Profile setup — @ai.tech.school

Manual steps (Instagram app → Edit Profile). Nothing here is automated —
see CLAUDE.md for why (same reasoning as the Runway/HeyGen and Composio
decisions: no credential handling, no live account access).

## Profile picture
Upload `profile.png` (1080×1080, rendered from `logo.svg`). Instagram
crops profile pictures to a circle — the bolt-and-wordmark design is
centered so nothing important sits in the corners that get cut off.

## Bio
```
Learn to build with AI, not just use it.
3 levels: Beginner → Intermediate → Expert.
Free lessons at the link below.
```
116 characters — well inside Instagram's 150-character bio limit, no
trimming needed.

## Website link
```
https://alexmonteiro65.github.io/ai-tech-school/
```
Paste into the "Website" field in Edit Profile (Instagram only allows one
clickable link there outside of Stories/Reels stickers).

## Name field (optional, distinct from @handle)
Consider setting the display name to "AI Tech School" — Instagram search
weighs the name field, and `ai.tech.school` alone doesn't contain the
words people are likely to search.
