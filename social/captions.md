## Post 3 — API vs MCP explained (`post-3-api-vs-mcp.png`)

**English**
> API vs MCP: an API is endpoints you call by hand, no memory, custom code per tool. MCP is a standard Claude can discover on its own, that keeps context across steps. Same goal, very different shape.
> #MCP #API #AITechSchool #ClaudeAI #AIagents

**Português (Brasil)**
> API vs MCP: a API são endpoints que você chama manualmente, sem memória, com código personalizado para cada ferramenta. O MCP é um padrão que o Claude descobre sozinho e mantém o contexto entre as etapas. Mesmo objetivo, formatos bem diferentes.
> #MCP #API #AITechSchool #ClaudeAI #AgentesDeIA

**Español (Latinoamérica)**
> API vs MCP: la API son endpoints que llamas a mano, sin memoria, con código a medida por herramienta. MCP es un estándar que Claude descubre solo y que mantiene el contexto entre pasos. Mismo objetivo, formas muy distintas.

## Post 6 — What is an AI Agent (`post-6-ai-agent.png`)

**English**
> An agent isn't just a chatbot — it's a loop. Observe, think, act, repeat, until the goal is done, largely without a human approving every step. That's the whole model.
> #AIagents #AITechSchool #ClaudeAI #MCP #Automation

**Português (Brasil)**
> Um agente não é só um chatbot — é um ciclo. Observar, pensar, agir, repetir, até a meta ser cumprida, em grande parte sem um humano aprovando cada etapa. Esse é o modelo inteiro.
> #AgentesDeIA #AITechSchool #ClaudeAI #MCP #Automacao

**Español (Latinoamérica)**
> Un agente no es solo un chatbot — es un bucle. Observar, pensar, actuar, repetir, hasta cumplir el objetivo, en gran parte sin que un humano apruebe cada paso. Ese es todo el modelo.
