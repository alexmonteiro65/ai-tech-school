What is an API and why you need one

Claude.ai is one way to use Claude. The API is how Claude gets built into everything else.

1

Explanation

API stands for Application Programming Interface — a defined way for one piece of software to ask another for something, and get a response back.

The restaurant analogy

Think of a restaurant. You don't walk into the kitchen and cook your own meal — you order from a menu, and a waiter carries your order to the kitchen and brings the result back. The menu and waiter are the API: a fixed, reliable way to ask for something without needing to know how the kitchen works inside.

Two ways to use Claude

  • Claude.ai — the chat website. Great for talking to Claude directly, one conversation at a time.
  • The Claude API — lets your own software send requests to Claude directly, so Claude can be built into an app, a website, or an automation — not just a chat window.
Why you need one: without an API, Claude only lives inside a chat window. With an API, your own product can ask Claude questions and use the answers automatically — which is exactly what Claude Code and MCP, coming up in the Intermediate path, are built on.
