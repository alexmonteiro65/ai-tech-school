## English

Hi, I'm Alex, founder of AI Tech School. One agent, many tools — that's what this lesson is about.

Composio is a platform that provides ready-made MCP connectors for dozens of popular tools — Slack, Gmail, Notion, Google Calendar, GitHub, Linear, and more — so you don't build a custom connector for every service you want an agent to use. Instead of one agent hard-wired to one tool, Composio lets a single agent reach many tools through the same MCP interface, and the agent picks the right tool for each part of a task.

Here's what that looks like end to end: a new customer onboarding workflow, four tools, one agent. Gmail sends the welcome email. Notion creates the onboarding document. Slack notifies the team. Google Calendar schedules the kickoff call. One agent, coordinating all four.

But there's a real design principle to hold onto here: more connected tools means more capability, but also more surface area for mistakes. Only connect what the workflow actually needs — every extra connection is one more way things could go wrong, not just one more thing the agent can do.

On the page, you'll match a set of real tasks to the tool best suited to handle each one, then check your understanding with three quick questions. See you in Lesson 3, the final one: deploying a fully automated pipeline.
