## English

Hi, I'm A.I.T.S., your AI Tech School guide — here's the detailed walkthrough for this lesson. Welcome to the Intermediate path — this is where Claude stops being something you chat with, and becomes something that actually works inside your own project.

Claude Code is Anthropic's official command-line tool. It lets Claude read, write, and run code directly inside your own project, in your own terminal. Here's how that's different from chatting in a browser: normally, you copy code out of a chat window, paste it into your project, and copy errors back in by hand. Claude Code skips all of that. It can see your actual files, propose edits, run tests or commands, and use tools — with your approval at each step you choose to review.

Installing it, conceptually, always follows the same shape, even though the exact command varies by operating system: install Node.js, open your terminal, install Claude Code with a single command, navigate to your project folder, and run "claude."

What changes once it's installed? You now have an AI collaborator that operates inside your real codebase, instead of a disconnected chat window you copy-paste between.

On the page, you'll put the setup steps in the right order yourself, then check your understanding with three quick questions. See you in Lesson 2: your first MCP connector.

Before you try the quiz below, here's a quick preview of the three questions and their answers. Question 1: What makes Claude Code different from chatting with Claude in a browser? Is it It's a different AI model entirely, It can directly read, edit, and run code in your real project, It only works on Windows, or It doesn't need any setup? The answer is It can directly read, edit, and run code in your real project — Claude Code operates on your actual files and can run commands, instead of you copy-pasting between a chat window and your project. Question 2: What do you need installed before Claude Code? Is it A specific code editor, Node.js, A GitHub account, or Nothing at all? The answer is Node.js — Node.js is the runtime Claude Code's install relies on — a GitHub account becomes useful later, but isn't required to install it. Question 3: How do you start a Claude Code session in a project? Is it Open a chat website, Run claude from your terminal inside the project folder, Email Anthropic, or Restart your computer? The answer is Run claude from your terminal inside the project folder — Once installed, running the claude command from inside your project folder starts a session there.
